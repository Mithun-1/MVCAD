# Download MVCAD

Click a link below to download MVCAD directly:

- **[Download for Windows — MVCAD.exe](https://github.com/Mithun-1/MVCAD/releases/latest/download/MVCAD.exe)**
- **[Download for Mac — Apple Silicon (.dmg)](https://github.com/Mithun-1/MVCAD/releases/latest/download/MVCAD-arm64.dmg)**

These links always download the newest published release. [View all releases](https://github.com/Mithun-1/MVCAD/releases).

## Windows

1. Click **Download for Windows** above.
2. Run the installer and follow the setup instructions.
3. Open **MVCAD** from the Start menu or desktop shortcut.

For future updates, click **Updates → Download update → Restart and update** in MVCAD. The installed application remains `MVCAD.exe`; no separate manual installer download is needed. If you installed version 0.1.0, install the latest version once to get the Updates button.

Requires 64-bit Windows. The preview installer is unsigned, so Windows may display a security warning.

## macOS — Apple Silicon

1. Click **Download for Mac — Apple Silicon** above.
2. Open the disk image.
3. Drag **MVCAD** into **Applications**.
4. Eject the disk image and open **MVCAD** from Applications.

For Macs with an Apple M-series chip. Intel Macs are not supported. The app has a local integrity signature but is not Apple-notarized; macOS may still block it. After attempting to open it, use **System Settings → Privacy & Security → Open Anyway** only if available and you trust this download. If macOS reports that it is damaged, discard the old copy and download the current release again. Do not disable Gatekeeper globally.

The **Updates** button checks for new Mac releases and opens the latest download. Replace MVCAD in Applications to update it. Automatic Mac installation is unavailable until Apple Developer ID signing is configured.
