# Get MVCAD

- **[Launch MVCAD — Mac / Browser](https://mithun-1.github.io/MVCAD/)**
- **[Download for Windows — MVCAD.exe](https://github.com/Mithun-1/MVCAD/releases/latest/download/MVCAD.exe)**

## Mac / Browser

1. Click **Launch MVCAD** above. No installer is needed.
2. Use **Open** to load an existing `.mvcad` project, or start a new part.
3. Use **Export → MVCAD** to save a project file to your computer.

The link opens the current published browser version. Save your project before refreshing to load an update. Projects from the desktop app or localhost are not transferred automatically; export them as `.mvcad` files and open them in the browser version.

## Windows

1. Click **Download for Windows** above to get the newest published Windows release.
2. Run the installer and follow the setup instructions.
3. Open **MVCAD** from the Start menu or desktop shortcut.

For future updates, click **Updates → Download update → Restart and update** in MVCAD. The installed application remains `MVCAD.exe`; no separate manual installer download is needed. If you installed version 0.1.0, install the latest version once to get the Updates button.

Requires 64-bit Windows. The preview installer is unsigned, so Windows may display a security warning.
